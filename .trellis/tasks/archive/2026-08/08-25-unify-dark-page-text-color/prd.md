# 统一深色页面文字颜色

## Goal

统一深色背景页面上的主要正文颜色，使其与顶部日志和已修正的“出门”瞬时页一致，避免部分页面文字呈现为偏暗、偏灰的米黄色。

## Background

- 顶部日志的主要文字使用 `#ffffff`，这是用户提供的视觉参照。
- “出门”瞬时页原先混用了 `#f0e6d2` 和更暗的 `#d8d0c0`，现已统一为 `#ffffff`。
- 源码排查发现相同的 `#f0e6d2` 主要正文色还出现在首页、角色选择、过夜结算和结局页。
- 项目中还存在用于禁用态、次要提示、警告、NPC 名称以及浅色背景文字的其他颜色，这些颜色承担独立的视觉语义。

## Requirements

- 深色背景上的主要标题和正文统一使用 `#ffffff`。
- 修正首页、角色选择页、过夜结算页和结局页中使用 `#f0e6d2` 的主要文字。
- 保留禁用态和次要提示的灰色、错误或警告色、NPC 名称强调色，以及浅色背景上的深色文字。
- 保留黑色纹理按钮上现有的按钮标签色；本次问题针对页面主要正文，不扩大到按钮主题重做。
- 已修正的“出门”瞬时页继续保持两行文字均为 `#ffffff`。

## Acceptance Criteria

- [x] 首页、角色选择页、过夜结算页、结局页和“出门”瞬时页的主要文字均呈现为与顶部日志一致的亮色。
- [x] 同一页面的主要正文不再因 `#f0e6d2` 或 `#d8d0c0` 出现无意的明暗差异。
- [x] 禁用、次要、警告、强调和浅色背景文字的语义颜色不发生变化。
- [x] TypeScript 类型检查通过。
- [x] 至少对“出门”瞬时页及一个其他受影响页面完成浏览器视觉验证。

## Out of Scope

- 重做完整配色系统或调整图片素材。
- 更改按钮、禁用态、次要说明、警告和特殊强调色。
- 调整字体、字号、字重、排版或文案。

## Technical Notes

- 这是单一视觉缺陷的轻量修改，使用 PRD-only 任务，不需要新增 `design.md` 或 `implement.md`。
- 修改前应搜索所有目标颜色用法，并逐处根据背景和语义判断，避免机械替换。
